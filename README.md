## Lord of the Flies Quiz

An animated quiz website (89 questions, 5 quizzes) that works on phones, tablets and computers.

- `index.html`: the whole site in one file. Open it in any browser, or host it on GitHub Pages.
- `.github/workflows/pages.yml`: publishes the site to GitHub Pages (turn on Settings → Pages → Source: GitHub Actions).
- `google-apps-script/`: the Google Apps Script version with the visitor counter and daily email report.
