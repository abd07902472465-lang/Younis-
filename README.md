# Younis-

Specializing in creating professional designs and graduation research papers.

موقع **يونس للتصاميم والبحوث**: صفحة عربية متحركة تعرض خدمات التصميم وبحوث التخرّج، مع اختبارات مراجعة مجانية لرواية *Lord of the Flies*.

## محتوى الموقع

| الملف | ما فيه |
| --- | --- |
| `index.html` | الصفحة الرئيسية: الخدمات، لماذا يونس، طريقة العمل، الاختبارات، الأسئلة الشائعة، نموذج الطلب |
| `css/style.css` | الألوان والخطوط والحركات، والوضع الليلي |
| `js/main.js` | الحركات التفاعلية، ونموذج الطلب عبر واتساب، و**إعدادات التواصل** في أعلى الملف |
| `quiz/index.html` | اختبار Lord of the Flies (‏89 سؤالاً في 4 اختبارات + اختبار مختلط) |

## الحركات في الموقع

- خلفية نقاط تتفاعل مع حركة الماوس، وقلم يرسم الشعار، وصفحة بحث تُنسَّق أمامك في الواجهة.
- قلم تظليل يمرّ على العنوان، وكتابة تلقائية لأسماء الخدمات، وشريط كلمات متحرك.
- بطاقات خدمات تميل مع الماوس وتصفية متحركة بين التصميم والبحوث.
- خطوات العمل تضيء بالتتابع عند التمرير، وأسئلة شائعة تُفتح بنعومة، وتبديل للوضع الليلي.
- سؤال تجريبي من الاختبار يُجاب عنه مباشرة في الصفحة الرئيسية.
- تحترم الحركات إعداد «تقليل الحركة» في الجهاز.

## قبل النشر: أضف أرقام التواصل

افتح `js/main.js` وعدّل القيم في أعلى الملف:

```js
const CONFIG = {
  whatsapp: '9647XXXXXXXXX', // رقمك بالصيغة الدولية، أرقام فقط
  email: '',
  instagram: '',
  telegram: '',
};
```

بعد إضافة رقم واتساب يرسل نموذج الطلب رسالة جاهزة إليه، ويظهر زر واتساب عائم في الموقع.

## الاختبارات

- رابط كل اختبار مباشرة: `quiz/index.html#chapter-2` و`#characters` و`#symbols` و`#novel` و`#mixed`.
- الأسئلة والإجابات كما هي من ملف الاختبار الأصلي.
- عدّاد الزوار والتقرير اليومي بالبريد في نسخة Google Apps Script لا يعملان على GitHub Pages، لأنهما يحتاجان خادم Google.

## النشر على GitHub Pages

1. ادمج هذا الفرع في `main`.
2. في المستودع افتح **Settings ← Pages**.
3. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة يظهر رابط الموقع في نفس الصفحة.

لتجربته على جهازك: افتح المجلد وشغّل `python3 -m http.server`، ثم ادخل إلى `http://localhost:8000`.
